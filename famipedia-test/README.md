# Famipedia（ファミペディア）

祖父母から聞いた話を、質問に答えていくだけで Wikipedia 風のページにまとめるアプリ。

名前は Family + Wikipedia から。「我が家の百科事典」という意味です。

**使う場面**：帰省して居間で二人きりになったとき。
スマホに出た質問をおじいちゃん・おばあちゃんに読み上げ、返ってきた話をその場で打ち込む。
AIが文章に整えてページに反映し、次の帰省では続きから再開できる。

## 動かし方

```bash
npm install     # 初回だけ
npm run dev     # http://localhost:5173 が開く
```

止めるときは `Ctrl + C`。Node.js が未インストールなら https://nodejs.org から。

**スマホで確認したいとき**は `npm run dev -- --host` で起動すると、
同じWi-Fiのスマホから `http://192.168.x.x:5173` で開けます。

## 画面の作り（レスポンシブ）

| 画面幅 | 表示 |
|---|---|
| 〜819px（スマホ） | 「質問」と「ページ」を下のタブで切り替え |
| 820px〜（タブレット・PC） | 左に記事、右に質問パネルを並べて表示 |

CSS は**スマホ基準で書いてあります**。
まず狭い画面用を書き、広いときだけ `@media (min-width: 820px)` で上書きする順番です。
逆にすると指定が打ち消し合って複雑になるので、この順番は崩さないでください。

スマホ向けに入れてある配慮：

- 入力欄の文字は `16px`（これ未満だと iPhone が勝手に拡大する）
- ボタンの高さは `50px`（指で押す領域は 44px 以上が目安）
- `env(safe-area-inset-bottom)` で iPhone のホームバーを避ける
- 端末がダークモードなら自動で暗い配色になる
- 「アニメーションを減らす」設定の人には動きを止める

## 「仮のJSONデータ」の話

チームで出ていた話は、おそらくこれです。

AIサーバーができるまで画面が作れない、という状態を避けるため、
**サーバーが返すはずのデータを先に JSON で用意してあります**。

```
src/mockData.json   ← 質問ごとの「返事の見本」
src/api.ts          ← USE_MOCK = true なら、その見本を返す
```

だから今の状態でも、AIが動いているかのように画面が完成します。
わざと 0.6〜1.1秒 待つようにしてあるので、読み込み中の見た目も確認できます。

**サーバーが完成したら `src/api.ts` の 1行を変えるだけです。**

```ts
export const USE_MOCK = false;   // ← true から false に
```

画面側のコードは一行も触りません。これが JSON で仮置きする理由です。

### データの形

`src/types.ts` に全部まとめてあります。ここがフロントとサーバーの契約書です。

送るもの：

```ts
{
  question: "最初の仕事は何でしたか？",
  answer:   "18の時に市内の織物工場に入って、糸の検品をしてた",
  person:   { name: "田中 一郎", birth: "1951年5月10日", place: "東京都", ... }
}
```

返ってくるもの：

```ts
{
  section:  "timeline",                    // AIがどのセクションか判断する
  year:     "1966年",                      // 年表用。無ければ null
  text:     "1966年、市内の織物工場に就職し、糸の検品を担当した。",
  followUp: "初めてお給料をもらったとき、何に使いましたか？"
}
```

`followUp` が返ってくると、**その場で追加の質問として画面に出ます**。
限られた時間で深く聞ける、というのがこのアプリの狙いなので、ここが肝です。

## AIを繋ぐとき

`server/index.example.js` が雛形です。プロンプトも書いてあります。

**APIキーをフロント側（src配下）に絶対に書かないでください。**
ブラウザの開発者ツールから誰でも読めます。請求は持ち主に行きます。
キーはサーバーの環境変数に置き、サーバーがAIを呼びます。

```bash
cd server
npm init -y
npm i express @anthropic-ai/sdk
export ANTHROPIC_API_KEY=xxxxx
node index.example.js
```

`vite.config.ts` を作って、開発中だけサーバーに転送する設定を足すと楽です。

```ts
export default {
  server: { proxy: { '/api': 'http://localhost:3000' } }
};
```

## 質問を増やす・変える

`src/questions.json` を編集するだけです。TypeScript は触りません。

```json
{
  "id": "q-pet",
  "section": "episode",
  "text": "昔、動物を飼っていましたか？",
  "hint": "名前や性格も聞けたら"
}
```

| 項目 | 意味 |
|---|---|
| `id` | 他と重複しない名前。**保存の目印なので後から変えない** |
| `section` | `summary` / `timeline` / `episode` / `message` |
| `text` | 画面に出る質問文 |
| `hint` | 下に小さく出る補足（省略可） |
| `field` | 基礎情報ボックスに入れる欄（省略可） |
| `infoOnly` | `true` なら本文には載せず、基礎情報だけに使う |

## チームでの分担

ファイルを分けてあるので、同時に作業してもぶつかりにくいです。

| 担当 | 触るファイル |
|---|---|
| 質問の内容を考える | `src/questions.json` だけ |
| 見た目・レスポンシブ | `style.css` だけ |
| AI連携 | `server/` と `src/api.ts` |
| 画面の動き | `src/main.ts` |
| 記事の見せ方 | `src/render.ts` |

`src/types.ts` は共通なので、**変えるときは必ず声をかけてください**。
ここがズレると全員が壊れます。

## Git の流れ

```bash
git pull                            # ① 作業前に必ず
git switch -c feature/ai-connect    # ② 作業用の枝を作る
# ...編集...
git add .

```

GitHub でプルリクエストを作り、他のメンバーが確認してから合体。
`main` に直接 push しないのがルールです。

## 今できること

- 幼少期から今まで、10個の質問を時系列で順に出す（飛ばすこともできる）
- 入力するとAI（今はモック）が整えて、該当セクションに反映
- AIが追加質問を提案し、その場で次の質問として出す
- 年表は年を拾って古い順に並べ替え
- 基礎情報ボックスの自動入力、写真1枚
- 端末に自動保存。リロードしても消えない
- Markdown として書き出し
- スクショ：記事（Wikipedia風の部分）を、見たままの形で縦長の画像1枚として保存（上にロゴ、下に作成日入り）

## まだできていないこと

- 複数人ぶんのページを切り替える
- 回答の音声入力（打ち込みが追いつかない場面用）
- 質問の読み上げ（画面をおばあちゃんに見せずに済む）
- 家族間での共有（サーバーとログインが必要）
- 回答のあとから編集・削除
